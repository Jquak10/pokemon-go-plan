How automatic scoring works

    

      PvE: current Pokémon GO stats and move-cycle data from the public
      Pokémon GO API are converted into a relative raid-attacker score.
    

    

      PvP: matching Master League scores come from PvPoke's public
      machine-readable ranking data.
    

    

      Rarity / urgency: calculated from Pokémon class plus how short
      the current raid window is.
    

    

      Mega utility: automatically derived for Mega/Primal raid forms
      from their PvE value plus the extra value of Mega/Primal raid support.
    

    

      The PvE score is a deterministic proxy, not a boss-by-boss Pokebattler-style
      simulation. It is designed to automate recommendations without scraping
      editorial websites or requiring a paid API.
