BACKUP & RECOVERY

Planner Backup

Download a portable JSON backup of this planner's preferences, Targets, battle history, and resource state. The backup does not contain your management link, calendar links, or credential hashes, but it can contain private notes and gameplay history, so store it somewhere you trust.

Download a current backup

Create a fresh backup after important Target, resource, or battle-log changes. If this management link is ever lost, create a new planner, save its new management link, then restore this backup into that new empty planner.

Restore into this empty planner

Use this after creating a new empty planner when recovering from a saved backup. Restore never changes this destination planner's management or calendar credentials. The destination must not already contain Targets, battle logs, usage/resource history, or saved Max tier overrides. Choose a backup, then type RESTORE exactly.
